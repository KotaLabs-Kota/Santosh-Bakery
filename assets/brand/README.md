# Santosh Baker's — logo assets

The original logo was supplied as a 150 × 150 px image. It has been rebuilt at
high resolution with **the same design** — same maroon oval plaque, same double
gold/cream ring, same swirling golden wheat wreath, same cream script wordmark —
only the quality changed: crisp edges, metallic wheat detail and clean lettering.

| File | Use |
| --- | --- |
| `santosh-bakers-logo-hd.png` | Master file, 2048 × 2048, white background — printing, signage, WhatsApp/Instagram profile |
| `santosh-bakers-logo-transparent.png` | 2048 × 2048 with transparency — best for the website, menus, packaging and dark backgrounds |
| `santosh-bakers-logo-tight.png` | 1600 × 1600, transparent, cropped tightly around the emblem |
| `santosh-bakers-logo-1024.png` | Web size, white background |
| `santosh-bakers-logo-512.png` | Small web / app icon size |

## Using it

- **Website:** use the transparent file over the cream `#FBF6EC` background, or the
  white/HD file on white sections. Keep clear space around the wreath equal to at
  least the height of the wordmark.
- **Print:** use the 2048 px master or ask for a vector (SVG/PDF) export at the
  final print size — the artwork was constructed at 2048 px so it stays sharp up
  to roughly 300 mm wide.
- **Minimum size:** 120 px wide for the full wreath lockup; below that, use just
  the oval plaque.

## Don'ts

Please keep the mark intact: don't recolour the wheat, stretch the oval, re-typeset
the wordmark, or separate the wreath from the plaque.
